# 👁️ Real-Time Scene Narrator

An AI-powered accessibility platform that converts a live camera feed into spoken narration for visually impaired users. Combines **Google Gemini 2.5 Flash Vision**, **ElevenLabs AI Voice Studio**, **Monocular Metric Distance Estimation Engine (v3)**, real-time in-browser object tracking, OCR text extraction, and turn-by-turn GPS navigation — all through a modern, responsive React interface.

---

## ✨ Key Features

- **🤖 Dedicated AI Integration (All-in-One)** — Single master control running Object Detection, Scene Narration, Metric Distance Estimation, and Sitting-Idle Medical Distress Monitoring simultaneously.
- **📷 Camera-to-Voice Narration** — Captures camera frames and speaks natural 2-sentence spatial descriptions generated by Google Gemini 2.5 Flash & ElevenLabs.
- **⚡ Ambient Obstacle Alerting** — In-browser TensorFlow.js COCO-SSD detects approaching hazards (cars, people, cyclists, furniture) with IoU tracking and EMA smoothing.
- **📏 Monocular Distance Calculation (v3)** — Computes precise metric distances (in meters) from 2D bounding boxes using a reference-height pinhole camera model with frame clipping and auto-detected FoV.
- **📋 Task Mode (OCR & Address Extraction)** — Point camera at signs, notices, or documents; AI extracts text and physical addresses with pre-processed image contrast enhancement and one-tap GPS launch.
- **🗺️ Turn-by-Turn GPS Voice Navigation** — Voice-guided navigation using OpenStreetMap Nominatim geocoding and OSRM routing; speaks turn instructions at 100m waypoint triggers.
- **🚨 Medical Emergency Monitoring** — Tracks posture and sitting idle duration; flags medical distress alerts if unresponsive for >10 seconds.

## 🔑 API Keys Setup

The backend requires **two** API keys (both offer free tiers):

### 1. Google Gemini API Key (Vision & OCR)
1. Visit [Google AI Studio](https://aistudio.google.com/apikey) and sign in.
2. Click **"Create API Key"** and select/create a Google Cloud project.
3. Copy your key (starts with `AIza...`) and paste it as `GEMINI_API_KEY` in `backend/.env`.

> 💡 **Free Tier Quota:** 15 requests/minute, 1,500 requests/day, 1,000,000 tokens/month.

### 2. ElevenLabs API Key (Text-to-Speech)
1. Sign up at [elevenlabs.io](https://elevenlabs.io).
2. Go to [Profile ➔ API Keys](https://elevenlabs.io/app/settings/api-keys).
3. Create a new key (starts with `sk_...`) and paste it as `ELEVENLABS_API_KEY` in `backend/.env`.

> 💡 **Free Tier Quota:** 10,000 characters/month. If quota is exceeded, the app automatically falls back to browser-native Web Speech API.

## 📐 Monocular Distance Calculation System (v3)

Real-Time Scene Narrator computes metric distance in meters from a single 2D bounding box using an advanced pinhole model with camera auto-calibration:

$$\text{Distance (meters)} = \frac{\text{focal\_length\_px} \times \text{real\_height\_m} \times \text{calibration}}{\text{bbox\_height\_px} \times 0.95}$$

### Key Mathematical & Geometric Features:
1. **Auto-Calibrated FoV**: Auto-detects horizontal Field of View ($58^\circ - 75^\circ$) based on camera resolution and aspect ratio (laptop vs. smartphone).
2. **Frame Clipping & Truncation Adjustment**: When a person or object stands close ($\approx 1.1\text{m}$), the camera crops their body. The engine detects frame clipping ($y_1 < 0.04$ or $y_2 > 0.96$) and adapts reference height from full standing ($1.70\text{m}$) to upper body ($0.85\text{m}$) or head/shoulders ($0.55\text{m}$).
3. **Multi-Cue Elevation Blending**: Blends optical pinhole geometry ($80\%$) with ground-plane elevation angles ($20\%$) for floor-level objects.
4. **Distance Zone Classification**:
   - 🔴 **Immediate** ($< 1.0\text{m}$) — *"within arm's reach"*
   - 🔴 **Very Close** ($1.0\text{m} - 2.0\text{m}$) — *"about 1.1 meters away"*
   - 🟡 **Close** ($2.0\text{m} - 4.0\text{m}$) — *"about 3 meters away"*
   - 🔵 **Medium** ($4.0\text{m} - 8.0\text{m}$) — *"roughly 6 meters away"*
   - ⚪ **Far** ($> 8.0\text{m}$) — *"far away"*

## 🔧 Troubleshooting FAQ

<details>
<summary><strong>❌ Gemini API Key Error (HTTP 403 / "Key reported as leaked")</strong></summary>

If your API key was publicly exposed, Google disables it. Get a fresh free key at [Google AI Studio](https://aistudio.google.com/apikey) and update `GEMINI_API_KEY` in `backend/.env`.
</details>

<details>
<summary><strong>❌ ElevenLabs Quota Exceeded (HTTP 401)</strong></summary>

If your ElevenLabs free tier (10,000 chars/month) is exhausted, the application automatically falls back to browser-native `SpeechSynthesis`. Audio narration will continue working seamlessly.
</details>

<details>
<summary><strong>❌ Camera Access Denied or Black Screen</strong></summary>

- Access the app via `http://localhost:5173` (localhost is exempted from HTTPS requirement).
- Ensure no other application (Zoom, Teams, Skype) is using the webcam.
- Grant camera permissions when prompted by the browser.
</details>

<details>
<summary><strong>❌ Nodemon / Binary Permission Denied on Linux/Mac</strong></summary>

Fix permissions on npm binaries:
```bash
chmod +x frontend/node_modules/.bin/* backend/node_modules/.bin/*
```
</details>
